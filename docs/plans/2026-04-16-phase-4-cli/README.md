## Overview

Usable standalone CLI tool. argparse with `index`, `update`, `search`, `stats`, `config` subcommands. Auto-discovery of `.km/` by walking parent directories. `config show/set/get` for LLM-friendly config management. JSON output mode. Installable via `uv tool install`.
